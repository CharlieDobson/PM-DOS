#group About PM-DOS|About PM-DOS
#nolist
PM-DOS is a fully 32-bit protected-mode operating system, fully
backward compatible with 16-bit applications.  The kernel runs above
the first megabyte and leaves nearly all of the 640K to the programs
under it: what was written for DOS runs as it did, and so does
Windows 3.1.  PM-DOS's own commands are 32-bit programs with no such
limit.

Key features:

{o} Long file names on FAT12, FAT16 and FAT32 disks.
{o} A disk cache, file sharing, expanded memory, a DPMI host and a
  mouse driver, all in the kernel, with nothing to load.
{o} IDE disks of any size, with UltraDMA up to UDMA6; partitions that
  FDISK can move and resize.
{o} CD-ROM drives, IDE and SCSI, with nothing to load.  MOUNT gives a
  disk image or an .ISO file a drive letter.
{o} USB keyboards, mice and disks, driven by the kernel.
{o} ISA Plug and Play cards, set up with ISAPNP.
{o} Delete protection: a deleted file comes back with UNDELETE until
  the space is needed.
{o} Country settings, code pages and keyboard layouts: COUNTRY=, CHCP
  and KEYB.
{o} SCANDISK, DEFRAG, DOSSHELL, EDIT, ACROREAD and HELP, all 32-bit;
  SCANDISK, DEFRAG and ACROREAD have a VBE graphics screen with /G.
{o} SHUTDOWN, which writes everything out and switches the machine off.
{o} A shell, CMD.EXE, with DOSKEY built in.  COMMAND.COM is there for
  the programs that start a shell of their own.

What it needs: a 386 or later, 4MB of memory, and 1.5MB of disk.

The command reference is the [[Contents]].  [[CONFIG.SYS commands|CONFIG]]
lists the statements CONFIG.SYS takes, and [[Starting PM-DOS|Starting]]
says what happens when the machine starts.

#plain Navigating|Moving Through PM-DOS Help
.topic Moving Through PM-DOS Help

                          Moving Through PM-DOS Help

 To scroll the text, click the arrows on the scroll bar, or press PAGE
 DOWN and PAGE UP.

 Links

 A link leads to another topic.  Links are shown between brackets, like
 this: [[DIR]].  Many topics start with links to their Notes and their
 Examples, which stay at the top of the window while the rest scrolls.

 To move the cursor to the next link

 {o} Press TAB.  Or press the first letter of the link.

 To move the cursor to the previous link

 {o} Press SHIFT+TAB.  Or press SHIFT and the first letter of the link.

 To read the topic a link leads to

 {o} Click the link.  Or move the cursor onto it and press ENTER.

 To see the contents

 {o} Click Contents on the bottom line, or press ALT+C.

 To read the topic after this one

 {o} Click Next on the bottom line, or press ALT+N.  The topics are in
   the order the help file has them, which is the contents' order.

 To go back to the topics you have read

 {o} Click Back on the bottom line, or press ALT+B.  Each press goes
   back one more topic.

#plain Searching|Finding Text in PM-DOS Help
.topic Finding Text in PM-DOS Help

                          Finding Text in PM-DOS Help

 Find, on the Search menu, looks for a piece of text in every topic of
 the help file, not only the one on the screen.

 Type the text and choose OK.  The search starts after the cursor and
 goes on through the topics that follow, round to the start of the
 file and back to where it began.  When the text is found, the topic it
 is in is shown with the cursor on it.  Press F3 to find the next one.

 Match Upper/Lowercase finds only text written with the same capitals.
 Whole Word skips the text when it is part of a longer word.

 With nothing found, PM-DOS Help says "Match not found".

#plain Context Help|Help on Menus and Dialogs|gah
.topic Help on Menus and Dialogs

                           Help on Menus and Dialogs

 F1 says what the thing in front of you is for.

 To get help on a menu

 {o} Press ALT to go to the menu bar, move to the menu with the LEFT and
   RIGHT ARROW keys, and press F1.

 To get help on a command in a menu

 {o} Open the menu, move to the command with the UP and DOWN ARROW keys,
   and press F1.

 To get help on a dialog box

 {o} Press F1, or choose its Help button.

 The help comes up in a box over whatever you were doing; choose OK to
 get back to it.

#plain Menus|Using the Menus
.topic Using the Menus

                               Using the Menus

 The menu bar at the top of the screen has three menus: File, Search
 and Help.

 To open a menu           With the mouse: click its name.
                          With the keyboard: press ALT, then the letter
                          shown in white in its name.  Or press ALT and
                          move to it with the LEFT and RIGHT ARROW keys,
                          then press ENTER or DOWN ARROW.

 To choose a command      With the mouse: click it.
                          With the keyboard: press its white letter, or
                          move to it with the arrow keys and press ENTER.

 To close a menu          Press ESC, or click somewhere else.

#plain Dialogs|Using a Dialog Box
.topic Using a Dialog Box

                              Using a Dialog Box

 Find and Print ask what you want in a dialog box.

 To move to a part of the box    Press TAB, or SHIFT+TAB to go back.
                                 Or press ALT and the white letter in
                                 its name.  Or click it.

 To choose an option             Move to the group with TAB and use the
                                 arrow keys.  Or click the option.

 To turn a check box on or off   Move to it and press the SPACEBAR, or
                                 click it.

 To press a button               Move to it and press ENTER, or click
                                 it.  ENTER anywhere in the box presses
                                 the button with the white brackets.

 To close the box doing nothing  Press ESC, or choose Cancel.

#plain Help Command Line|Starting PM-DOS Help from the Command Line
.topic Starting PM-DOS Help from the Command Line

                   Starting PM-DOS Help from the Command Line

 The HELP command starts PM-DOS Help.

 {o} Type HELP on its own for the contents.

 {o} Type HELP and the name of a command or a CONFIG.SYS statement to
   open at its topic.  For example:

   help copy
   help country

 A name PM-DOS Help does not know gets "Match not found", and then the
 contents.

 HELP reads its text from HELP.HLP, which is looked for in the current
 directory, then where HELP.EXE itself is, then along the PATH.  The
 file is plain text and can be changed with EDIT; the [[HELP]] topic
 says how it is laid out.

#plain File Menu|m.f
.topic File Menu

{b}File Menu{p}

The File menu has Print and Exit.

Print writes the topic on the screen to a printer or a file.  Exit
leaves PM-DOS Help.

To open the menu, click File, or press ALT and then F.  To choose a
command, click it, or press its white letter.
#plain Search Menu|m.s
.topic Search Menu

{b}Search Menu{p}

The Search menu has Find and Repeat Last Find.

Find looks for text in every topic.  Repeat Last Find, or F3, looks
for the same text again from where the cursor is.

To open the menu, click Search, or press ALT and then S.  To choose a
command, click it, or press its white letter.
#plain Help Menu|m.h
.topic Help Menu

{b}Help Menu{p}

The Help menu has How to Use PM-DOS Help and About.

How to Use PM-DOS Help explains the window, the links and the keys.
About shows the version of PM-DOS Help.

To open the menu, click Help, or press ALT and then H.  To choose a
command, click it, or press its white letter.

#plain Exit Command

{b}Exit Command{p}

#plain Find Command
.topic Find Command

{b}Find Command{p}

Looks for text in every topic of the help file, starting after the
cursor.  The topic the text is found in is shown with the cursor on
it.  A dialog box asks for the text, and whether capitals and whole
words matter.
#plain Repeat Last Find Command
.topic Repeat Last Find Command

{b}Repeat Last Find Command{p}

Looks again for the text Find last looked for, from the cursor on.
F3 does the same.

Before Find has been used, Repeat Last Find looks for the word the
cursor is on, or the word to its left.  With no word there it asks for
the text, as Find does.

{ll}{-x58}{lr}

Find What holds the text to look for; the word the cursor was on is
offered.  Up to 127 characters.

Match Upper/Lowercase finds only text written with the same capitals
and small letters.  Whole Word skips the text when it is part of a
longer word: "cat" is not found in "catalogue".

The search starts after the cursor and goes through every topic, round
to the start of the file and back to where it began.  F3 finds the
next one.
#plain Print Dialog
.topic Print Dialog

{b}Print Dialog{p}

Writes the topic on the screen to a printer or a file.

Choose Printer to print on the port named, LPT1 unless Printer Setup
has chosen another.  Choose File and type a name to write the topic to
a file; a name without a path goes in the current directory.  A file
of that name is replaced.

The text is written as it is shown, with a form feed at the end.
#plain Printer Setup Dialog
.topic Printer Setup Dialog

{b}Printer Setup Dialog{p}

Chooses the port the printer is on: LPT1, LPT2, LPT3, COM1 or COM2.
The choice lasts until PM-DOS Help is left.
