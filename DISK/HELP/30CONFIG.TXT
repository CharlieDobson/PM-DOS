#! 30CONFIG.TXT - CONFIG.SYS: the statements, what each one takes,
#! and the topics about starting the machine.  CONFIG.TXT on the boot
#! disk says the same things at more length.
#group CONFIG.SYS Commands|CONFIG|CONFIG.SYS|config
CONFIG.SYS is a text file in the root of the boot drive.  PM-DOS reads
it once at startup, before the shell, and sets itself up as it says.
Each line is one statement.  A ; or REM at the start of a line makes
it a remark.

Every statement MS-DOS knew is accepted, so a CONFIG.SYS from an
MS-DOS machine boots without errors; some of them do nothing here.  A
statement PM-DOS does not know at all stops with "Unrecognized command
in CONFIG.SYS", so a typing mistake shows.

The statements MS-DOS had:

{i}[[Break|BREAK=]]                    [[Lastdrive|LASTDRIVE=]]{p}
{i}[[Buffers|BUFFERS=]]                  [[Menucolor|MENUCOLOR=]]{p}
{i}[[Country|COUNTRY=]]                  [[Menudefault|MENUDEFAULT=]]{p}
{i}[[Device|DEVICE=]]                   [[Menuitem|MENUITEM=]]{p}
{i}[[Devicehigh|DEVICEHIGH=]]               [[Numlock|NUMLOCK=]]{p}
{i}[[Dos|DOS=]]                      [[Rem|REM]]{p}
{i}[[Drivparm|DRIVPARM=]]                 [[Set|SET=]]{p}
{i}[[Fcbs|FCBS=]]                     [[Shell|SHELL=]]{p}
{i}[[Files|FILES=]]                    [[Stacks|STACKS=]]{p}
{i}[[Include|INCLUDE=]]                  [[Submenu|SUBMENU=]]{p}
{i}[[Install|INSTALL=]]                  [[Switches|SWITCHES=]]{p}
{i}[[Installhigh|INSTALLHIGH=]]{p}

The statements that are PM-DOS's own.  On MS-DOS these jobs took a
driver or a program - EMM386, SMARTDRV, SHARE, MODE - and on PM-DOS
they are in the kernel, so those programs are not loaded:

{i}[[Autocheck|AUTOCHECK=]]                [[Keyrate|KEYRATE=]]{p}
{i}[[Cache|CACHE=]]                    [[Lfn|LFN=]]{p}
{i}[[Cdrom|CDROM=]]                    [[Nulltrap|NULLTRAP=]]{p}
{i}[[Dpmi|DPMI=]]                     [[Scsi|SCSI=]]{p}
{i}[[Ems|EMS=]]                      [[Share|SHARE=]]{p}
{i}[[Ide32|IDE32=]]                    [[Undelete|UNDELETE=]]{p}
{i}[[Idecable|IDECABLE=]]                 [[Usb|USB=]]{p}
{i}[[Idedma|IDEDMA=]]                   [[Wincache|WINCACHE=]]{p}

CONFIG.SYS can also hold several configurations, with a menu at
startup to choose one.  See [[Multiple Configurations|Multi-config]].

{b}The order{p}

Lines run top to bottom, with three exceptions: SWITCHES= is read
before anything else, DOS= next, and INSTALL= lines run last, after
every driver has loaded.  Only the first 16K of the file is read.

{b}Starting without it{p}

Hold Shift, or press F5, while "Starting PM-DOS..." is on the screen,
and neither CONFIG.SYS nor AUTOEXEC.BAT is run.  Press F8 to be asked
about each line instead.  See [[Starting PM-DOS|Starting]].
#group Starting PM-DOS|Starting|Startup|Boot
When the machine starts, PMIO.SYS and PMDOS.SYS are loaded from the
root of the boot disk, CONFIG.SYS is read, the shell named by SHELL=
(CMD.EXE if there is no such line) starts, and the shell runs
AUTOEXEC.BAT.

{b}What has to be in the root{p}

PMIO.SYS, PMDOS.SYS, CONFIG.SYS and AUTOEXEC.BAT.  Everything else can
be in a directory of its own: [[SHELL=]] says which, and the kernel
looks for its other files beside the shell, then in the root.

{b}Safe mode{p}

PM-DOS waits two seconds after "Starting PM-DOS..." for Shift or F5.
With either pressed it says "Safe mode", skips CONFIG.SYS and
AUTOEXEC.BAT, and goes straight to the prompt.  Use this when a line
in either file stops the machine from starting.  SWITCHES=/F skips
the wait, and SWITCHES=/N turns the keys off: see [[SWITCHES=]].

{b}Confirming each line{p}

Press F8 while "Starting PM-DOS..." is on the screen, or on the
startup menu, and each line of CONFIG.SYS is shown before it runs.  Y
runs the line and N skips it.  ESC runs the rest without asking, and
F5 skips the rest and AUTOEXEC.BAT too.  Then PM-DOS asks whether to
process AUTOEXEC.BAT; with Y, its lines are asked about the same way.

To be asked about one line only, put a ? after its name in
CONFIG.SYS, as in DEVICE?=C:\DOS\ANSI.SYS.

{b}The startup menu{p}

A CONFIG.SYS with a [menu] block shows a menu first, to choose which
configuration to start.  See [[Multiple Configurations|Multi-config]].

{b}AUTOEXEC.BAT{p}

A batch file like any other, run by the first shell.  The one on the
PM-DOS disk sets the prompt and the path; it is where KEYB goes, and
any program that is to run at every start.  See [[Batch Commands|Batch]].

{b}Restarting{p}

Ctrl+Alt+Del restarts the machine after everything owed to the disks
is written.  [[SHUTDOWN]] switches it off.
#group International Commands|International|Intl
PM-DOS can show dates, times and numbers the way a country writes
them, sort its letters in its order, and take its keyboard.

{i}[[Country|COUNTRY=]]{p}
    In CONFIG.SYS: the country, and with it the date order, the
    separators, the currency, and the table of capitals.  The tables
    come from COUNTRY.SYS.

{i}[[Chcp|CHCP]]{p}
    Shows or changes the code page, within the pages the country has.

{i}[[Keyb|KEYB]]{p}
    Loads a keyboard layout from KEYBOARD.SYS.  It goes in
    AUTOEXEC.BAT.

There is no NLSFUNC to load and no DISPLAY.SYS: the kernel reads
COUNTRY.SYS by itself, and the characters on the screen are the ones
in the video card, code page 437 on most.
#group Multiple Configurations|Multi-config|Multiconfig|Menu
CONFIG.SYS can hold more than one configuration.  Each one is a block
of lines that starts with its name in brackets, and a menu at startup
chooses which block is used:

    [menu]
    MENUITEM=NORMAL,Normal start
    MENUITEM=NOUSB,Leave USB to the BIOS
    MENUDEFAULT=NORMAL,5

    [common]
    FILES=40

    [NORMAL]
    USB=ON

    [NOUSB]
    USB=OFF

{b}The blocks{p}

[menu]
    The startup menu.  It holds [[MENUITEM=]], [[SUBMENU=]],
    [[MENUDEFAULT=]], [[MENUCOLOR=]] and [[NUMLOCK=]] lines only.

[common]
    Lines used by every configuration.  The lines above the first
    block are common too.  There can be more than one [common] block.

[name]
    A configuration, used when it is chosen.  [[INCLUDE=]] adds the
    lines of another block.

Without a [menu] block, only the common lines are used.

{b}The menu{p}

The UP and DOWN ARROW keys, or a number, pick a choice, and ENTER
starts it.  F5 starts without CONFIG.SYS and AUTOEXEC.BAT, and F8
turns on confirming each line: see [[Starting PM-DOS|Starting]].

{b}In AUTOEXEC.BAT{p}

The name of the chosen block is in the CONFIG environment variable,
so AUTOEXEC.BAT can do something different for each one:

    GOTO %CONFIG%
    :NORMAL
    NET USE K: \\SERVER\SHARE
    GOTO END
    :NOUSB
    ECHO USB is left to the BIOS.
    :END
#topic AUTOCHECK=|Autocheck
#title AUTOCHECK=
Says what happens at startup to a hard disk that was not shut down
properly.

{b}Syntax{p}

    AUTOCHECK=ON | ASK | OFF

{b}Parameters{p}

ON
    CHKDSK X: /F checks and repairs the drive before AUTOEXEC.BAT
    runs.  This is the setting without the line.  In safe mode, ON
    works like ASK.

ASK
    Asks first.

OFF
    Only names the drive.

{b}Related Commands{p}

See [[CHKDSK]] and [[SCANDISK]].
#notes
{b}The mark{p}

A drive is marked when something writes to it, and unmarked once
everything is written and no file is left open for writing, which is
done by the time the prompt comes back.  So switching off at the
prompt is safe; switching off while a program is saving a file, or
while Windows is running, leaves the drive marked.

{b}Where CHKDSK is{p}

CHKDSK.EXE has to be in the shell's directory or in the root of the
boot drive.
#examples
    AUTOCHECK=ASK
#topic BREAK=|Break (CONFIG.SYS)
#title BREAK=
Sets the extended Ctrl+C checking flag at startup.

{b}Syntax{p}

    BREAK=ON | OFF

{b}Parameters{p}

ON | OFF
    The flag programs read with INT 21h AX=3300h.  OFF without the
    line.  PM-DOS itself does not yet look at the flag.

{b}Related Commands{p}

The [[BREAK]] command changes it at the prompt.
#examples
    BREAK=ON

#examples

#topic CACHE=|Cache (CONFIG.SYS)
#title CACHE=
Sets the size of the disk cache, and whether it writes behind.

{b}Syntax{p}

    CACHE=max[,min[,ON | OFF]]
    CACHE=OFF

The default is cache=[total_mem / 8],on.

{b}Parameters{p}

max
    The most the cache may grow to, in KB.  Use K or M to specify 
    kilobytes or megabytes respectively.  E.g.: CACHE=4M is CACHE=4096.
    Default value is 1/8 of extended memory.

min
    The smallest value the cache can shrink to.  Default value for
    min is a 1/4 the value of max.  With less than 2MB of extended
    memory there is no cache.  The same number twice gives a fixed
    size.

ON | OFF
    Write-behind, for hard disks only.  Default is ON.  Data
    in cache is written before the prompt returns.  OFF disables
    write caching, and so does VERIFY ON.

OFF
    When used alone with no other options, disables disk cache entirely.

{b}Related Commands{p}

The [[CACHE]] command shows the cache and controls it while the
machine runs.  For the cache under Windows, see [[WINCACHE=]].
#notes
{b}What is cached{p}

Floppies, CD-ROMs and drives from loaded block drivers are only
read-cached.  Hard disks are read- and write-cached.
#examples
    CACHE=4M
    CACHE=2048,2048,OFF
#topic CDROM=|Cdrom
#title CDROM=
Chooses the drive letter of the first CD-ROM drive.

{b}Syntax{p}

    CDROM=x

{b}Parameters{p}

x
    The letter.  Any other CD-ROM drives follow it.  Without the line
    they come after the hard disks.  A letter a hard disk has is
    ignored.

{b}Related Commands{p}

[[CDEX]] lists the drives and their letters.  [[SCSI=]] is for drives
on SCSI cards.
#notes
{b}Under Windows{p}

The first CD-ROM on an IDE cable keeps its letter under Windows when
RMCD.SYS is where the shell is, or in the root of the boot drive.
RMCD.SYS is an ordinary file: SYS does not copy it, COPY does, and
without it only the CD-ROM under Windows is missing.  The disc's
file names are displayed in 8.3 format.  Other CD-ROM drives are
not shown under Windows.

{b}Starting from a CD-ROM{p}

When PM-DOS is started from a CD-ROM, the drive it was started from
gets this letter, and the other CD-ROM drives follow it.
#examples
    CDROM=R
#topic COUNTRY=|Country
#title COUNTRY=
Sets the country: how dates, times, numbers and money are written,
which letters are capitals of which, and how SORT orders them.

{b}Syntax{p}

    COUNTRY=code[,[page][,file]]

{b}Parameters{p}

code
    The country's international dialling code: 044 is the United
    Kingdom, 049 Germany, 033 France.  Without the line the country is
    the United States, 001.

page
    A code page.  Without one, the first the file lists for the
    country, which is 437 wherever 437 has the country's letters.

file
    The file of tables.  Without one, COUNTRY.SYS where the shell is,
    then in the root of the boot drive.

{b}Related Commands{p}

[[CHCP]] changes the code page later; [[KEYB]] loads the keyboard.  See
[[International Commands|International]].
#notes
{b}What follows the country{p}

DIR, DATE, TIME and the prompt use the country's date order and
separators.  The thousands separator in DIR's sizes is the country's.

{b}No NLSFUNC{p}

The kernel goes back to COUNTRY.SYS by itself when a program asks
about another country or CHCP changes the page.  PM-DOS reads
MS-DOS's COUNTRY.SYS as well as its own.

{b}Not the keyboard, not the screen{p}

COUNTRY= does not change the keyboard: that is KEYB, in AUTOEXEC.BAT.
Neither changes the characters the screen shows, which are the ones
in the video card.

#topic DEVICE=|Device
#title DEVICE=
Loads a device driver.

{b}Syntax{p}

    DEVICE=[drive:][path]filename [options]

{b}Parameters{p}

[drive:][path]filename
    The driver.

options
    Command line options which are passed directly to the driver.

{b}Related Commands{p}

[[DEVICEHIGH=]] loads a driver into upper memory.  A resident program
goes in with [[INSTALL=]].
#notes
{b}What PM-DOS has already{p}

The mouse, the CD-ROM drives, the cache, expanded memory, file
sharing and DPMI are in the kernel.  Do not load MOUSE, MSCDEX,
SMARTDRV, EMM386, HIMEM.SYS, SHARE or a DPMI host.

{b}Block drivers{p}

A block driver's drives get the letters after the last disk.

{b}32-bit drivers{p}

A 32-bit driver loads with the same line.  PM-DOS loads 32-bit
drivers above the first megabyte, leaving more conventional memory
free for 16-bit drivers and programs.

A TSR or driver that extends BIOS functions such as a printer
redirector or a VESA BIOS Extensions driver (VBE) has to be loaded
with DEVICE= or with INSTALL= in CONFIG.SYS.

{b}.EXE drivers{p}

A driver can be an .EXE file, such as SETVER.EXE.  DEVICE=C:\SETVER.EXE
loads the version table that [[SETVER]] keeps.  Put the line above any
driver listed in the table.
#examples
    DEVICE=C:\WINDOWS\IFSHLP.SYS
    DEVICE=C:\DRIVERS\ASPI4DOS.SYS
    DEVICE=C:\NE2000.SYS /P:300 /I:10
    DEVICE=C:\SETVER.EXE
#topic DEVICEHIGH=|Devicehigh
#title DEVICEHIGH=
Loads a 16-bit DOS device driver into upper memory.

{b}Syntax{p}

    DEVICEHIGH=[drive:][path]filename [options]

{b}Parameters{p}

[drive:][path]filename
    The driver.

options
    Command line options which are passed directly to the driver.

{b}Related Commands{p}

Upper memory is set up by [[DOS=]].  See [[DEVICE=]] for what a driver
is, and [[LOADHIGH]] for programs.
#notes
{b}When it loads low{p}

Without DOS=UMB, or when no upper memory block is big enough, the

#examples
    DOS=UMB
    DEVICEHIGH=C:\DRIVERS\ANSI.SYS
#topic DOS=|Dos
#title DOS=
Sets up upper memory for 16-bit drivers and programs to load into.

{b}Syntax{p}

    DOS=HIGH | LOW[,UMB | NOUMB]

{b}Parameters{p}

HIGH | LOW
    Accepted for backwards compatibility.  Has no effect on PM-DOS.

UMB
    Sets up the blocks between 640K and 1MB for DEVICEHIGH, INSTALLHIGH
    and LOADHIGH.

NOUMB
    No upper memory.  This is the default setting.

{b}Related Commands{p}

See [[DEVICEHIGH=]], [[INSTALLHIGH=]] and [[LOADHIGH]].  [[MEM]] shows
the blocks.  [[EMS=]]'s page frame takes 64K of the same room.
#examples
    DOS=HIGH,UMB

{b}Parameters{p}

ON
    Turns DPMI services on for DOS programs.  This is the default setting.

OFF
    Disables the integrated DPMI host.

#topic DRIVPARM=|Drivparm
#title DRIVPARM=
For backwards compatibility only.  Has no effect under PM-DOS.

{b}Syntax{p}

    DRIVPARM=/D:number [/C] [/F:factor] [/H:heads] [/I] [/N] [/S:sectors]
             [/T:tracks]

PM-DOS queries the drives themselves.  MULTITRACK= is ignored the same way.
#topic EMS=|Ems
#title EMS=
Enables or disables expanded memory (LIM 4.0) for 16-bit DOS programs.

{b}Syntax{p}

    EMS=NO | AUTO | segment

Default is no expanded memory.

{b}Parameters{p}

NO
    Disables expanded memory.

AUTO
    A 64K page frame is found in upper memory, which leaves 64K less
    for DOS=UMB.

segment
    Specifies the page frame address: C000 to E000, on a 16K boundary.
    EMS=D000 puts it at D000.

{b}Related Commands{p}

[[MEM]] shows the frame and the pages.  See [[DOS=]] for the upper
memory it shares.
#notes
{b}What it does{p}

Expanded Memory is used by real-mode DOS applications that require
more memory than 640K.  Memory pages are mapped into and out of the
page frame in upper memory, leaving more conventional memory free
for application use.  EMS memory is pooled with extended memory up
to 32MB.
#examples
    EMS=AUTO
    EMS=D000

#topic IDE32=|Ide32
#title IDE32=
Chooses 32-bit reads from the IDE data port.

{b}Syntax{p}

    IDE32=OFF | AUTO | ON

{b}Parameters{p}

OFF
    16-bit reads only.

AUTO
    Each drive is tested first, and gets 32-bit reads when it passes.
    This is the default setting.

ON
    32-bit reads without the test.  If the drive cannot handle 32-bit
    transfers, this setting may result in data loss or system crashes.

{b}Related Commands{p}

[[IDEDMA=]] chooses DMA, which does not use the data port at all.
#notes
{b}If a disk reads garbage{p}

A disk that reads incorrectly or produces garbage should use IDE32=OFF.
#examples
    IDE32=OFF
#topic IDECABLE=|Idecable
#title IDECABLE=
Specifies IDE cable in use.

{b}Syntax{p}

    IDECABLE=AUTO | 40 | 80

{b}Parameters{p}

AUTO
    PM-DOS will test which cable is in use.  This is the default
    setting.

40 | 80
    The number of wires in the cable.  ATA3 (UltraDMA/66) and faster
    require an 80-wire cable.  This setting is for all IDE channels.

{b}Related Commands{p}

Put the line above [[IDEDMA=]].
#examples
    IDECABLE=80
#topic IDEDMA=|Idedma
#title IDEDMA=
Chooses how IDE disks move their data.

{b}Syntax{p}

    IDEDMA=OFF | AUTO | ON | mode

{b}Parameters{p}

OFF
    Programmed Input/Output (PIO) only.

AUTO
    Keeps the mode set by the BIOS, and falls back to PIO when there is
    none.  This is the default setting.

ON
    The fastest mode the drive, the controller and the cable can handle.

mode
    UDMA0 to UDMA6 specifies the fastest UltraDMA mode PM-DOS should use.
    MWDMA0 to MWDMA2 sets multi-word DMA mode.  Slower than UDMA but faster
    than PIO.

{b}Related Commands{p}

See [[IDECABLE=]] and [[IDE32=]].
#notes
{b}When a transfer fails{p}

A DMA transfer that fails puts that disk back to PIO until the next
boot.  A CRC error above UDMA2 drops the disk to UDMA2 first.
#examples
    IDEDMA=ON
    IDEDMA=UDMA2

#topic MENUCOLOR=|Menucolor
#title MENUCOLOR=
Sets the colors of the startup menu.  Used only in a menu block.

{b}Syntax{p}

    MENUCOLOR=x[,y]

{b}Parameters{p}

x
    The text color, 0 to 15.

y
    The background color, 0 to 15.  Default is 0, black.

    0  Black      4  Red        8  Gray          12  Bright red
    1  Blue       5  Magenta    9  Bright blue   13  Bright magenta
    2  Green      6  Brown     10  Bright green  14  Yellow
    3  Cyan       7  White     11  Bright cyan   15  Bright white

#topic MENUDEFAULT=|Menudefault
#title MENUDEFAULT=
Sets the menu choice that starts highlighted, and how long the menu
waits before using it.  Used only in a menu block.

{b}Syntax{p}

    MENUDEFAULT=blockname[,timeout]

{b}Parameters{p}

blockname
    The block of the default choice.  Without MENUDEFAULT=, the first
    choice is the default.

timeout
    Seconds to wait, 0 to 90, before the default is used.  Without a
    timeout the menu waits for ENTER.  With 0 the menu is not shown at

#topic USB=|Usb (CONFIG.SYS)
#title USB=
Turns PM-DOS's USB support on or off, and specifies how many drive
letters to keep for USB disks.

{b}Syntax{p}

    USB=ON | OFF
    USB=ON,n

{b}Parameters{p}

ON
    PM-DOS drives the USB controllers itself.  USB keyboards, mice
    and disks work, and one drive letter is kept for a USB disk, after
    every other letter.  This is the default setting.

ON,n
    Enable and reserve n letters, up to 4, for a machine with more than one
    USB disk plugged in at once.

OFF
    The controllers are left to the BIOS.  A USB keyboard or disk then
    works only as far as the BIOS's own USB support takes it.

{b}Related Commands{p}

[[USB]] lists the controllers, the devices and the disk units.
#notes
{b}When it takes effect{p}

The controllers are taken from the BIOS once CONFIG.SYS has been read,
so the line can be anywhere in the file.  Safe mode (Shift or F5 at
start) always leaves the controllers to the BIOS regardless of setting.

{b}The drive letter{p}

USB disks are handled like any other removable media.  The drive letter
will be available regardless whether a drive is plugged in or not.
Attaching a USB drive will connect it to the first letter, and so on up to
the maximum reserved letters specified.  A drive letter with no disk
will report "Not ready."

A disk plugged in during boot keeps the letter the boot process
gave it, and its USB letter stays empty.  A blank disk gets no letter
from the boot process.

{b}Under Windows{p}

When Windows or another real-mode program takes control of the machine,
the USB controllers go back to the BIOS until the application ends and
control returns to PM-DOS.
#examples
    USB=ON,2
    USB=OFF

#topic SHELL=|Shell
#title SHELL=
Chooses the command interpreter, and with it the directory PM-DOS
keeps its files in.

{b}Syntax{p}

    SHELL=[drive:][path]filename [options]

PM-DOS defaults to CMD.EXE if found in the root of the boot drive.

{b}Parameters{p}

[drive:][path]filename
    Specifies the command interpreter to use.  The specified directory
    is where PM-DOS looks for other files such as COMMAND.COM,
    COUNTRY.SYS, KEYBOARD.SYS, etc.  If a directory is not specified,
    PM-DOS defaults to the root of the boot drive.

options
    The interpreter's switches.  Without /P, AUTOEXEC.BAT is skipped.

{b}Related Commands{p}

See [[CMD]] for the switches, and [[Starting PM-DOS|Starting]].
#notes
{b}A system in C:\DOS{p}

To specify the CMD.EXE command interpreter and PM-DOS files
are located in C:\DOS, use:

    SHELL=C:\DOS\CMD.EXE /P

This automatically places C:\DOS in the PATH as well if one
is not specified.
#examples
    SHELL=C:\DOS\CMD.EXE /P

#topic WINCACHE=|Wincache
#title WINCACHE=
Sets the cache used while Windows runs.

{b}Syntax{p}

    WINCACHE=size[,LOG]
    WINCACHE=OFF

{b}Parameters{p}

size
    In KB, or with K or M after it, up to 4M.  Without the line, an
    eighth of free extended memory is used.

LOG
    Writes RMCACHE.LOG on the boot drive when Windows exits, with the
    hit counts.

OFF
    No cache under Windows.

{b}Related Commands{p}

For the cache the rest of the time, see [[CACHE=]].
#notes
{b}Why a second cache{p}

The standard PM-DOS disk cache returns its memory to the system
when Windows starts.  This setting specifies the size of the real-
mode disk cache for use with Windows 3.x.  MS-DOS's SMARTDRV disk
cache is emulated so that Windows for Workgroups 32-bit file access
driver can turn it off when it takes over.  Write caching is always
disabled.
#examples
    WINCACHE=2M,LOG
