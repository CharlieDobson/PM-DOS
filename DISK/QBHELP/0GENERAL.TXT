#entry Using Help
{b}Getting help{p}
    F1          Help on the keyword at the cursor, in the window above
                the program.  The keys stay with the program.
    Shift+F1    This topic.
    F1          In a menu or a dialog: what the item does.
    Help menu   The Index, the Contents, and help on the keyword.

{b}In the help window{p}
    Tab         The next link; Shift+Tab the one before.
    Enter       Follows the link at the cursor.  F1 does the same.
    Alt+F1      Back to the topic shown before.  The Back link at the
                top of the window does the same.
    Ctrl+F1     The next topic in the help file.
    A letter    In the Index: to that letter's keywords.
    Esc         Closes the help window.
    F6          Moves to the next window, leaving the help open.

A link is shown between arrows: [[Contents|contents]].  With a mouse, a
double click on a link follows it; the scroll bar moves through the topic.
QBASIC.HLP must be beside QBASIC.EXE, in PM-DOS's own directory, in the
current directory, on the PATH, or where Options > Help Path says.
#topic Getting Started
#context survival
#entry Getting Started
{b}Typing a program{p}
Type the program in the big window, one statement to a line.  When the
cursor leaves a line, QBasic checks the line and puts its keywords in
capitals.  A mistake is reported at once, with the cursor on it.

{b}Running it{p}
Shift+F5 runs the program from the start.  Its output goes on the
output screen; at the end, a key brings QBasic back.  Ctrl+Break stops a
program that runs on.  F4 shows the output screen again.

{b}Finding mistakes{p}
F8 runs one statement at a time; F9 sets a breakpoint where the program
should stop; F5 runs on.  The Immediate window at the bottom (F6 moves
there) runs a line as soon as Enter is pressed - PRINT x shows a
variable of a stopped program.

{b}Saving it{p}
Alt, F, S saves the program; Alt, F, A saves it under a new name.  Alt,
F, O loads one.

{b}Leaving{p}
Alt, F, X goes back to DOS.  QBasic asks first if there are changes not
yet saved.

See Also  [[Using Help|usinghelp]]  [[Shortcut Keys|keys]]  [[Keywords by Task|tasks]]  [[Index|index]]

#topic Syntax Conventions
#context syntax
#entry Syntax Conventions
How the syntax of a statement is written in this help:

    {b}KEYWORD{p}       A word to type as shown (in any case).
    name          Something to put in its place: a variable, a number,
                  an expression.
    [ item ]      The item may be left out.
    { a | b }     Either a or b.
    item, ...     The item may be repeated, with commas between.
    name%         The suffix says the type wanted: % INTEGER, & LONG,
                  ! SINGLE, # DOUBLE, $ STRING.  A name with no suffix
                  takes a number of any type.

Punctuation - commas, parentheses, semicolons - is typed as shown.

#entry Data Types
Each variable holds one type of value.  The type comes from the name's
suffix, from AS in a declaration, or from a DEFtype statement; without
any of these the type is SINGLE.

  Type      Suffix  Bytes  Holds
  INTEGER     %       2    whole numbers from -32,768 to 32,767
  LONG        &       4    whole numbers from -2,147,483,648 to
                           2,147,483,647
  SINGLE      !       4    numbers to about 7 digits, up to 3.402823E+38
  DOUBLE      #       8    numbers to about 15 digits, up to
                           1.797693134862315D+308
  STRING      $      ---   text of 0 to 32,767 characters
  STRING * n          n    text of exactly n characters (in a TYPE, a
                           DIM, COMMON or SHARED)

A TYPE statement makes a record type of these.  ANY, in a DECLARE, lets a
parameter take an argument of any type without checking.

    DIM count AS INTEGER, total AS DOUBLE
    DIM name AS STRING * 20
    total# = 1.5D+100

See Also  [[DIM]]  [[TYPE]]  [[DEFINT]]  [[CONST]]  [[DECLARE]]
#topic Arithmetic Operators
#context arith
#key MOD Operator
#entry Arithmetic Operators
#entry Relational Operators
From the first done to the last:

    ^           Raises to a power: 2 ^ 10 is 1024.
    -           Negation: -x.
    *  /        Multiplication and division.
    \           Integer division: both sides are rounded to whole
                numbers first, and the result has its fraction cut off.
    MOD         The remainder of an integer division: 7 MOD 3 is 1.
    +  -        Addition and subtraction.  + also joins strings.
    =  <>  <  >  <=  >=
                Comparisons: -1 for true, 0 for false.  Strings compare
                character by character, by their codes.
    NOT, AND, OR, XOR, EQV, IMP
                The [[Boolean Operators|boolean]], last of all.

Parentheses change the order.  Operators of the same rank go from left to
right.  A result is given the most precise type of its operands; / and ^
give at least a SINGLE.  "Division by zero" and "Overflow" are the errors
to expect.
#topic Boolean Operators
#context boolean
#key AND Operator
#key OR Operator
#key XOR Operator
#key EQV Operator
#key IMP Operator
#key NOT Operator
#entry Boolean Operators
#entry Logical Operators
They work on whole numbers bit by bit (16 bits for an INTEGER, 32 for a
LONG; other numbers are rounded first).  A comparison gives -1 (every bit
set) for true and 0 for false, so they join comparisons as well:

    NOT x       Each bit turned over: NOT 0 is -1.
    x AND y     Bits set in both.
    x OR y      Bits set in either.
    x XOR y     Bits set in one but not the other.
    x EQV y     Bits that are the same in both.
    x IMP y     Bits that are set in y, or clear in x.

NOT is done first, then AND, OR, XOR, EQV and IMP, all after the
comparisons.  Both sides are always worked out.

    IF age >= 18 AND member THEN PRINT "Welcome"
    flags = flags OR 4
    IF (flags AND 4) = 0 THEN PRINT "bit 2 is clear"

See Also  [[Arithmetic Operators|arith]]  [[IF]]
#topic Metacommands
#context meta
#key $DYNAMIC Metacommand
#key $STATIC Metacommand
#entry Metacommands
A metacommand is written in a remark (REM or ') and changes how the lines
after it are read:

    {b}REM $DYNAMIC{p}  or  {b}' $DYNAMIC{p}
    {b}REM $STATIC{p}   or  {b}' $STATIC{p}

$DYNAMIC: arrays dimensioned after it are made when their DIM runs, and
ERASE frees them.  $STATIC (the default): arrays dimensioned with
constant bounds are made before the program starts, and ERASE only sets
their elements to zero.  An array whose DIM has a variable bound is
always dynamic.

See Also  [[DIM]]  [[REDIM]]  [[ERASE]]  [[REM]]

{b}Moving{p}
    Arrow keys            A character or a line
    Ctrl+Left, Ctrl+Right A word
    Home                  The first character of the line's text;
                          again for column 1
    End                   The end of the line
    Ctrl+Home, Ctrl+End   The top or the bottom of the window's text
    PgUp, PgDn            A window's worth up or down
    Ctrl+PgUp, Ctrl+PgDn  A window's width left or right
    Ctrl+Up, Ctrl+Down    Scrolls a line without moving the cursor

{b}Selecting and the clipboard{p}
    Shift with a moving key   Selects text
    Shift+Del                 Cuts the selection
    Ctrl+Ins                  Copies the selection
    Shift+Ins                 Pastes
    Del                       Deletes the selection, or a character

{b}Typing{p}
    Ins (or Ctrl+V)  Inserting or typing over
    Backspace        Deletes the character before the cursor
    Ctrl+T           Deletes the rest of the word
    Ctrl+Y           Cuts the line
    Ctrl+N           Breaks the line at the cursor; the cursor stays
    Tab, Shift+Tab   Indents and takes back the indent, of the line or
                     of each selected line
    Ctrl+P, then a key   Types the key's character, a control code too

The WordStar keys work too: Ctrl+Q then S, D, R or C moves; Ctrl+Q then
F finds and A changes; Ctrl+Q then Y cuts to the end of the line.

#topic QBasic Command Line
#context cmdline
#entry QBasic Command Line
{b}QBASIC{p} [/B] [/EDITOR] [/G] [/H] [/MBF] [/NOHI] [[/RUN] [path]file]

    {o} /B        For a monochrome screen (accepted; Options > Display
                sets the colours).
    {o} /EDITOR   Starts the PM-DOS Editor (EDIT) instead.
    {o} /G        Writes the screen straight to the CGA memory
                (accepted; the screen is always written fast).
    {o} /H        As many lines as the display gives: 43 on EGA, 50 on
                VGA.
    {o} /MBF      MKS$, MKD$, CVS and CVD read and write Microsoft Binary
                Format, as programs from older BASICs expect.
    {o} /NOHI     For a display without bright colours (accepted).
    {o} file      The program to load.  .BAS is assumed.
    {o} /RUN      Runs the program as soon as it is loaded.  A SYSTEM in
                the program then goes back to DOS.

QBasic needs a math coprocessor: a 486DX, or a 386 with a 387.

#topic QBasic on PM-DOS
#context pmdos
#entry PM-DOS, QBasic on
This QBasic is a native 32-bit program for PM-DOS.  It runs the programs
QBasic 1.1 runs, with these differences:

    {o} It needs a math coprocessor (a 486DX, or a 386 with a 387), and
      works in the coprocessor's full precision.  The last digit of a
      SIN or EXP can differ from Microsoft's.
    {o} Arrays may be bigger than 64K.
    {o} There is no real mode.  DEF SEG, PEEK and POKE reach the
      program's own variables, the output screen (B800 and A000), the
      BIOS data area (0040) and the ROMs; other addresses read 0.
    {o} CALL ABSOLUTE gives "Advanced feature unavailable".
    {o} SHELL starts the PM-DOS command interpreter.
    {o} A line typed in the Immediate window while the program is stopped
      runs in the stopped program; a change to the program's text means
      starting again.
    {o} Long file names can be used wherever a file is named.
#topic ASCII Character Codes
#context ascii
#entry ASCII Character Codes
The 256 characters of the display, with the code CHR$ takes and ASC
gives.  0 to 31 are control codes when printed: 7 beeps, 8 backspaces,
9 tabs, 10 and 13 end lines.  Codes 9, 10 and 13 show blank here.
