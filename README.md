# PM-DOS
A protected-mode 32bit disk operating system

## Project Goal:
A fully backward compatible protected mode DOS with native 32bit
application support (no need for DOS4G or DOS32/A).

## Target System Requirements
- 80386 CPU
- 4MB of RAM
- 4MB hard disk space (will vary based on included utils)

## Supported Compilers
Written and compiled with Open Watcom WASM.
Should be MASM v6.1x compatible.
