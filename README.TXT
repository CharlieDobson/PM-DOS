PM-DOS - Protected Mode DOS
===========================

A full featured 32-bit operating system with backward
compatibility with 16-bit DOS applications.

System Requirements
===================
CPU: 80386
RAM: 4MB
HDD: 4MB

Features
========
PnP device support
File delete protection
Built-in disk cache
Up to UltraDMA/133 support
SATA (AHCI) hard disks and CD-ROM drives
Built-in optical drive support
Starts from a CD-ROM (El Torito)
FAT12/16/32 and exFAT file systems
Long File Names
MBR and GPT partitioned disks
FAT partition resizing
Disk and CD-ROM images mounted as drives
USB keyboards, mice and flash drives
TCP/IP and NetBEUI networking
Network drives on Windows shares (NET USE)
File sharing to other computers (SMBSRV)
FTP, TELNET, WGET with HTTPS, SNTP and PING
Runs Windows 3.1 and Windows for Workgroups 3.11
Multiple configurations in CONFIG.SYS
ACPI-aware shutdown command
VBE 2.0 with linear frame buffer
QBasic, which can make EXE files
Online help (HELP), with every command in it

What PM-DOS is NOT
==================

PM-DOS was not designed with security in mind.
Its goal was to be a natural evolution to
MS-DOS 16-bit as a single user operating
system.  PM-DOS is not multi-threaded and
does not support multi-CPUs or cores.
